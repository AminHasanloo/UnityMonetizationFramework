# UnityMonetizationFramework
 (Unity IAP Framework + Unity Ads Manager) با پشتیبانی از کافه‌بازار، مایکت، گوگل‌پلی (Unity IAP)، زرین‌پال (REST) و شبکه‌های تبلیغاتی AdMob + تپسل + ironSource/LevelPlay؛ همه‌چیز از طریق یک ScriptableObject در اینسپکتور پیکربندی می‌شه و با Scripting Define Symbols به‌صورت خودکار فعال/غیرفعال می‌گرده.
