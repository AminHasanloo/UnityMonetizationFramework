# Changelog

## 1.0.0 (Initial release)
- ScriptableObject settings (single place) for Ads & IAP (Google Play, CafeBazaar, Myket, Zarinpal).
- Ad adapters: AdMob, Tapsell, ironSource (LevelPlay) with unified API.
- IAP providers: GooglePlay (Unity IAP), CafeBazaar, Myket, Zarinpal (REST) with unified API.
- Editor window to configure and write scripting define symbols automatically.
- Sample demo scripts for testing rewarded, interstitial, banner; and IAP purchase flows.
